## agentside(config)

```ts
function agentside(config: AgentsideConfig): {
  handle(request: Request, next: () => Promise<Response>): Promise<Response>;
  serve(request: Request, pathname?: string): Promise<Response>;
};
```

`handle` negotiates the request and either answers with markdown or calls `next()`. See [Content negotiation](/negotiation). `serve` treats the request as an explicit markdown request for `pathname`, which defaults to the request URL's path. The returned object's type is exported as `Agentside`.

## AgentsideConfig

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `routes` | `Record<string, Source>` | required | Page paths or patterns mapped to their twin's source. |
| `variants` | `Record<string, Variant[]>` | `{}` | Variants per route pattern. See [A/B variants](/variants). |
| `accept` | `"q-value" \| "contains"` | `"q-value"` | `"contains"` serves markdown whenever `Accept` mentions `text/markdown`, matching CDN rules that can't parse q-values. |
| `skip` | `string[]` | `[]` | Path prefixes that `handle` never touches. |
| `cache` | `{ ttlMs?, capacity? } \| false` | `{ ttlMs: 300000, capacity: 1000 }` | In-memory cache settings. See [Caching](/caching). |
| `timeoutMs` | `number` | `5000` | Timeout for each source load, including retries. |
| `retries` | `number` | `2` | Retries for remote sources on network errors and 5xx. |
| `cacheControl` | `string` | `"public, max-age=3600"` | `Cache-Control` for markdown responses. |
| `noindex` | `boolean` | `true` | Adds `X-Robots-Tag: noindex` to markdown responses. |
| `linkHeader` | `boolean` | `true` | Adds a `Link` header to HTML responses that have a twin. |
| `normalize` | `boolean` | `true` | Replaces typographic Unicode with ASCII. |
| `onServe` | `(event: ServeEvent) => void` | | Runs after every successful markdown response. |
| `onError` | `(error: unknown, path: string) => void` | | Runs when a source fails. |

## Sources

```ts
type Source = string | LocalSource | RemoteSource;
type LocalSource = (context: RenderContext) => string | null | undefined | Promise<string | null | undefined>;

function remote(
  url: string | ((context: RenderContext) => string),
  options?: { headers?: Record<string, string> }
): RemoteSource;
```

## Types

```ts
type AgentPurpose = "training" | "search" | "user-action";
type Format = "html" | "markdown";

interface Agent {
  readonly name: string;
  readonly vendor: string;
  readonly purpose: AgentPurpose;
}

interface RenderContext {
  readonly path: string;
  readonly params: Readonly<Record<string, string>>;
  readonly request: Request;
  readonly agent: Agent | null;
}

interface ServeEvent {
  readonly path: string;
  readonly variant: string;
  readonly agent: Agent | null;
  readonly status: number;
  readonly cached: boolean;
  readonly durationMs: number;
}
```

## agentside/build

```ts
import { prerender } from "@usenotra/agentside/build";

const { written, skipped } = await prerender(config, {
  outDir: "dist/client",
  paths: ["/", "/pricing", "/blog/hello"],
  siteUrl: "https://example.com",
});
```

`prerender` renders each path once with the cache off and writes it to `outDir` at its `.md` URL (`/` becomes `index.md`). `paths` defaults to every route without parameters. Twins that return `null` end up in `skipped`. If any twin fails, it throws one error listing every failing path, so a broken twin stops the build instead of reaching agents.

### prerenderHtml

```ts
import { prerenderHtml } from "@usenotra/agentside/build";

const pages = await prerenderHtml({
  dir: "dist",
  outDir: "dist",
  siteUrl: "https://example.com",
  selector: "main",
  exclude: ["/admin"],
  llms: { title: "Acme", description: "We make anvils." },
});
```

Converts every built `.html` file in `dir` (except `404.html` and `500.html`) to markdown and writes it to `outDir` at its `.md` URL. Only the `selector` element is converted, which defaults to `<main>`, then `<article>`, then `<body>`. Elements with `data-ai-ignore` are dropped, elements with `data-ai-content` are replaced by the attribute's markdown, `<dl>` lists become `**term**: definition` items, cards (a link wrapping a heading) become `[Heading](url): text` and tables become GFM tables. With `llms`, it also writes `llms.txt` and `llms-full.txt`. Returns the converted pages; any failure throws one error listing every failing path.

### htmlToMarkdown

`htmlToMarkdown(html, { selector?, siteUrl? })` converts a single HTML document with the same rules.

### vercelRoutes

`vercelRoutes(paths?)` returns `{ rewrites, headers }` for `vercel.json`. Requests with `Accept: text/markdown` or a known AI agent user agent are rewritten to the page's `.md` file, and `.md` responses get `Content-Type: text/markdown`, `Vary` and `X-Robots-Tag`. Without `paths` it covers every path without a file extension; with `paths` it covers only those pages. Set `accept: "contains"` on any `agentside()` handler that sits behind these rules so both layers make the same decision.
