Any runtime with a `fetch(request)` entry point can wrap its handler in `handle`.

## Install

```bash
npm install @usenotra/agentside
```

## Cloudflare Workers

With static assets, the Worker has to run before the asset handler so it can negotiate every request. Set `run_worker_first` in your Wrangler config.

```jsonc wrangler.jsonc
{
  "name": "acme",
  "main": "src/worker.ts",
  "assets": { "directory": "./dist", "binding": "ASSETS", "run_worker_first": true }
}
```

```ts src/worker.ts
import { agentside, remote } from "@usenotra/agentside";

const twins = agentside({
  routes: {
    "/": "# Acme\n\nAcme sends invoices your customers actually pay.",
    "/docs/[...path]": remote(({ params }) => `https://cms.acme.dev/docs/${params.path}.md`),
  },
});

export default {
  fetch(request: Request, env: { ASSETS: Fetcher }) {
    return twins.handle(request, () => env.ASSETS.fetch(request));
  },
};
```

Responses from `env.ASSETS.fetch` have immutable headers. Agentside detects that and copies the response before it adds the `Link` and `Vary` headers, so no extra code is needed.

The in-memory cache lives per isolate. Rely on `Cache-Control` for caching across isolates and regions.

### Static output on Workers

If your assets are a static build, run `prerenderHtml` over the asset directory after the build so every page has a `.md` file next to it. Then let the Worker read those files from the asset binding instead of writing routes by hand.

```ts src/worker.ts
import { agentside } from "@usenotra/agentside";
import { env } from "cloudflare:workers";

const fromAssets = async (path: string, request: Request) => {
  const response = await env.ASSETS.fetch(new URL(path, request.url));
  return response.ok ? response.text() : null;
};

const twins = agentside({
  routes: {
    "/": ({ request }) => fromAssets("/index.md", request),
    "/[...path]": ({ params, request }) => fromAssets(`/${params.path}.md`, request),
  },
  cache: false,
});

export default {
  fetch: (request: Request) => twins.handle(request, () => env.ASSETS.fetch(request)),
};
```

`cache: false` keeps the Worker from holding copies of files the asset layer already caches. Pages without a `.md` file return `null`, so agents get the HTML page.

## Bun.serve

```ts server.ts
import { agentside } from "@usenotra/agentside";

import { app } from "./app";

const twins = agentside({
  routes: {
    "/": "# Acme\n\nAcme sends invoices your customers actually pay.",
    "/pricing": () => Bun.file("content/pricing.md").text(),
  },
});

Bun.serve({
  port: 3000,
  fetch: (request) => twins.handle(request, () => app(request)),
});
```

`app` is whatever renders your HTML, for example another framework's fetch handler.

### Static output on Bun

For a static folder served by Bun, convert it once after the build and read the generated files in a catch-all route.

```ts server.ts
import { agentside } from "@usenotra/agentside";
import { prerenderHtml } from "@usenotra/agentside/build";

await prerenderHtml({ dir: "public", llms: { title: "Acme" } });

const twin = async (path: string) => {
  const file = Bun.file(`public${path}`);
  return (await file.exists()) ? file.text() : null;
};

const twins = agentside({
  routes: {
    "/": () => twin("/index.md"),
    "/[...path]": ({ params }) => twin(`/${params.path}.md`),
  },
});

Bun.serve({
  port: 3000,
  fetch: (request) => twins.handle(request, () => serveStatic(request)),
});
```

`serveStatic` stands for whatever serves the folder today. Run `prerenderHtml` in your build step instead of at startup when the folder is large. If you deploy the folder to Vercel instead, write `vercelRoutes()` to `vercel.json` as described in [Static sites](/static-sites#negotiating-at-the-cdn).
